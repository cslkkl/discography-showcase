### 定向規則例外

Task 04 採完整 Folia 舞台方向，允許在獨立、按需載入的歌詞模組內使用必要執行期依賴和獨立建置。
歌詞模組也允許逐曲配色與原模式需要的字體、光影及 WebGL；這些例外不擴展到站點其餘部分。
首頁和歌手頁仍沿用原架構、四族字體與主題層級，不能整站遷移或全面安裝播放器框架。
實作 Task 04 時將此例外同步進對應規則與架構，明列作用域及產物載入方式。
維護者已同意「每曲整體風格 + 歌內段落變化」的組合方向，不需要再問要第一種還是第二種。
API 密鑰、付費使用和整首音頻對外上傳不因本文自動獲得授權。
AGPL 來源、發布義務及與原 MIT 程式的關係按 Task 04 規格核實，不擅自更改整個專案許可。

- 可見文案用繁體原文，沿用本地化流程，預設簡體；歌詞正文維持原資料，不任意改寫。

- 保留已存在的視覺資產，不以裝飾性佔位圖取代真實專輯封面。

- 預設不截圖、不讀圖、不輸入參考庫圖片；使用源碼、DOM、真實指針、CSSOM、文字日誌與逐幀數值。

## 統一自查與完成流程

每項都按「實作 → 對照效果 → 正常流程 → 邊界 → 修復 → 回歸 → 記錄」完成。

### 開始前

- 檢查工作樹，記下其他人的改動與本次基線。
- 執行會受本項影響的既有檢查，區分既有失敗與本次新增失敗。
- 說明會動到的檔案、共用狀態與資料契約；找出舊實作，避免新增平行重複路徑。

### 每項檢查

- JS/CSS：執行 `npm run lint` 及受影響流程的瀏覽器 E2E。
- 資料：改來源後重建，對照公開生成物與實際頁面，不手改生成檔。
- Markdown：執行 `npm run check:docs` 和 `npm run check:eol`。
- 根設定、套件或載入契約：執行 `npm run check`，另跑新增模組的建置及測試。
- 修改 JS/CSS 後執行 `npm run stamp`，重開頁面確認實際載入新版本。
- 互動使用真實點擊、鍵盤或觸控；不得以 `element.click()`、強制點擊或關掉遮擋驗收冒充使用者操作。
- 動效用頁內 rAF 量測，視口以 `innerWidth` 自證，樣式量測前將頁面帶到前景。
- 3D 命中依真實指針與 `:hover` 取樣，不以 `elementsFromPoint` 的列表代替真實命中。
- 桌面 1440×900、1366×768；平板 768×1024；手機 390×844、320×740；另驗手機橫屏。
- 改動後檢查可見長文字、固定層遮擋、焦點落點、繁簡切換、減少動效與無橫向溢出。
- 避免為通過檢查而放寬斷言、跳過模式、隱藏報錯或更新不正確的數字。

### 每項收尾

- 在進度表寫明檔案、測試命令、實測結果、失敗修復及未驗部分。
- 功能、程式檢查與必要回歸通過才標「實作驗證完成」；缺人工審美確認另外註明。
- 有受阻子項就寫明具體原因和恢復方法，不把整項標完成後只在末尾藏限制。
- 同步實際受影響的模組手冊、架構與規則，避免多份互相矛盾的狀態表。

## Task 04：Folia 完整舞台與 AI 情緒呈現

**狀態起點：** 只有基礎三行舞台，完整移植及兩層 AI 尚待實作。

**想呈現的效果**

從歌曲檔案進入全屏後，使用者可以選用 Folia 豐富的文字排版、逐字動畫、背景、光影與展示模式。
每首歌由 AI 推薦整體風格，同一首歌又隨段落自然調整力量、光影與必要的模式變化。
例如整體藍灰的歌曲，主歌平靜，副歌更亮、更有力度，間奏留下背景，結尾逐漸平靜。
這是效果例子，不代表所有歌曲都使用相同配色或固定段落模板。

**修改提示詞**

完整執行 [Task 04 專項規格](task-04-folia-stage.md)，不得只讀本節摘要。

1. 固定 Folia 版本，逐項移植 14 種實際渲染模式及必要背景、設定和資源。
2. 以獨立按需載入模組接本站唯一音訊狀態，保持進度、暫停、切歌和回檔案行為。
3. AI 讀取完整可用歌詞及音樂摘要，輸出經 schema 校驗的主題、模式建議和參數；結果快取。
4. 完整音訊預分析提供能量及候選段落，結合歌詞推斷時間配置；不把隨機切換稱作情緒分析。
5. 支援自動、手動選模式、鎖定及恢復自動；段落變化不等於每句換模式。
6. 逐行 LRC 合成掃光要標明估算，不偽稱真逐字時間；已有逐字資料則使用真時間。
7. 無 AI、無詞、載入失敗、WebGL 不可用和 30 秒公開試聽各有可用降級。
8. 本機音訊與歌詞不對外上傳；AI 密鑰不進瀏覽器公開包；核對上游 AGPL 及資源許可。

**自查**

- [ ] 14 模式完成表與必要背景清單逐項有證據，沒有同效果改名冒充。
- [ ] 真實 AI 端到端及完整歌曲段落分析有脫敏證據；無憑證部分如實標受阻。
- [ ] 單音訊、進度跳轉、快速切歌、逾期請求、手動鎖定及資源釋放通過。
- [ ] 桌面及手機有可用入口、播放控制和退出，沒有空舞台或吞掉焦點。
