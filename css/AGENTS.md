# css/ — 规则层

继承根规则，见 [../AGENTS.md](../AGENTS.md)。

css/ 特有约束：

- 樣式由兩個檔案承擔：`style.css`（全站樣式，分節以 `/* ── N. 名稱 ── */` 標註，
  新增樣式歸入既有分節）與 `motifs.css`（每位歌手的專屬母題，按 `data-motif` 選組）
- 歌手層主題使「第二強調色」有了明確邊界：同一歌手頁內只有一個強調色 `--accent`，
  其上的前景色只能是 `--accent-on`；母題裝飾一律取 `var(--accent)`，不得自帶新色。
  唯一的例外是**作品層打光** `--amb`（歌手頁 `.hero::before` / `.hero-art::*` 與入口
  `.ld-glow`）：它由當前封面的平均色派生、隨唱片換色，與抽屜面板的 `--tint` 同性質，
  只當背景光暈、不參與文字／邊框／按鈕／狀態的著色；歌手的 `--accent` 仍獨佔所有控制項。
  改動打光時以低透明度（≤ .30）並保留一層極淡的 `--accent`，維持歌手的色彩人格
- 圓角只用兩個檔位：控制項 `--r-pill`，面與圖 `--r`。
  **明列例外**：入口的 `.ld-cta` 與歌手頁 `.hero-cta` 內是文字型按鈕（透明底、無圓角、
  hover 時底部長出 1px 強調色細線）。其餘圖示型控制項仍一律 `--r-pill`
- **需要真縱深的重疊封面堆，透視要用每元素自己的 `perspective()` 函式，
  不要用祖先 `perspective` ＋ 子層 `transform-style: preserve-3d`**：
  後者形成真正的 3D 脈絡，被 `translateZ` 推遠的卡片在**真實指標**下命中不到自己
  （實測主視覺命中率只有 72.3%，真實點擊穿透到宿主 `div.fan`），而
  `document.elementsFromPoint` 仍會回報該卡，所以 DOM 斷言驗不出來。
  改成每張卡自己的 `perspective(1400px)` 後命中率 100%、縱深幾乎無損
  （遠端封面投影寬 241 → 235px）。不重疊的展櫃／封面牆保留 `preserve-3d` 無妨
- **分組屬性會壓平 3D 子樹**：`opacity < 1`、`filter`、`clip-path`、`mask` 都會把元素的
  子樹壓平。要「整台變暗」時不要把 `opacity` 下在 3D 卡片堆的容器上（外側封面會在
  過渡頭尾各跳一次，實測 241 → 257.7 → 241），要下到每一張卡自己身上
- 新增動效必須在 `prefers-reduced-motion` 區塊內給出降級；
  **降級要連 `animation-delay` / `transition-delay` 一起歸零**——只把時長壓成 0
  而留著延遲，分階段入場的元素會停在起始態（`opacity: 0`）近三秒才出現
- 錯峰入場的 `transition-delay`（隨序號遞增）只服務入場，必須與懸停回應解耦：
  入場結束後清零（`is-settled` 一類的類名），否則懸停要等「序號 × 步長」才響應。
  本專案年輪曾因此讓第 40 圈等兩秒多；主視覺換片也曾因此要 1458–2263ms 才停穩
  （入場錯峰騎在換位上，修法是 `.fan.is-shifting/.is-arriving .fan-card` 歸零延遲）
- 中文文字的限寬與量度用 `rem` / `px`，**不要用 `ch`**：`ch` 以 CJK 字體解析只有半個
  漢字寬，`30ch` 會把一句話切成兩三行（實測 391px 下 229.9px／3 行）。
  本專案已在 `.ls-inner`、`.ha-note`、`.ld-note` 三處踩到
- 入場用的過渡時長（如 `stroke-dashoffset` 1.15s）不得套用到懸停回饋；
  懸停回饋控制在 200ms 上下，圖例一類的行高亮 160ms 上下
- 捲動驅動的位移寫在自訂屬性上，由 JS 以 rAF 更新，不在 CSS 內做逐幀動畫
- 不引入外部 CSS 框架或預處理器

檔案職責與變更影響面見 [README.md](README.md)。
