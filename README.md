# 声之年轮 · 周杰伦录音室专辑全集

一个纯静态的专辑陈列网站：十六张录音室专辑、一百七十五首作品，时间跨度 2000 至 2026。
零依赖、零构建、可离线运行，双击 `index.html` 即可打开。

---

## 打开方式

**直接打开（推荐）**

双击 `index.html`。所有素材（封面、字体、脚本）都在本地，断网也能完整显示。

**本地服务器（可选）**

```powershell
node _data/serve.mjs 8099
# 然后访问 http://127.0.0.1:8099
```

## 功能

全站共 **14 个展示面**，每个用不同的布局语言，避免重复。

| # | 区域 | 说明 |
|---|---|---|
| 1 | 开场 | 印章 + 年份计数器，遮罩帘幕 |
| 2 | 主视觉 | 五张封面扇形叠放，跟随指针做 3D 视差 |
| 3 | 数据带 | 专辑数、曲目数、总时长、跨度 |
| 4 | 歌名带 | 随页面滚动缓慢横向位移（非自动循环） |
| 5 | **年轮** | 十六圈同心环，由内而外依年份排列；圈宽是曲目数，颜色取自该张封面平均色。悬停切换读数，点击进入专辑 |
| 6 | 专辑展柜 | 桌面端横向卷动：纵向滚动驱动封面横向推进，当前专辑提亮，其余压暗 |
| 7 | **试听播放** | 每首曲目都可播 30 秒官方试听；底部播放列含封面、进度、上一首/下一首/连续播放，详情页有「试听整张」 |
| 8 | 作品年表 | 十六行发行年表，悬停指示，点击进入详情 |
| 9 | **年代分期** | 十六张分成四個階段（起點／盛期／擴張／回望），各带一段取捨说明与封面组 |
| 10 | **封面墙** | 十六张封面四列排开，悬停有跟随指针的光泽 |
| 11 | **数据面** | 累积曲目曲线（SVG）、发行间隔条形、曲目数与时长对照、四个关键数字 |
| 12 | **长篇与短篇** | 最长的十二首与最短的八首，依实际时长排序 |
| 13 | **合作者** | 从曲目标题的合唱标注解析而来，五位合作者各自的曲目 |
| 14 | **代表曲** | 每张专辑挑出的关键曲目，共 38 首 |
| — | 曲目总表 | 收录全部 175 首的检索表，支持繁简互通搜索与空状态 |
| — | 专辑详情 | 全屏抽屉：封面、发行信息、编辑文字、完整曲目与时长 |
| — | 随机一曲 / 繁简切换 | 顶栏按钮；全站一键切换，选择写入 localStorage |

「数据面」里的每一个数字都由曲目资料直接算出，没有估算值：

- 累计 175 首，总录音时长 11 小时 44 分
- 发行间隔中位数 14 个月，最长一次是《周杰倫的床邊故事》到《最偉大的作品》的 6.1 年
- 单张曲目数区间 10 至 13 首；最短是《Jay》10 首，最长是《11月的蕭邦》52:02
- 最长单曲《以父之名》5:42，最短《Intro》0:30

## 播放

**音源是 Apple 官方随目录提供的 30 秒试听片段**（`previewUrl`，与专辑、曲目、封面同一次请求返回）。
本项目**没有存储任何录音**，也没有抓取或转码音频。

- 175 首全部有试听，0 首缺失
- 播放列固定在底部：封面、曲名、`专辑 · 第 N 首`、进度条（可拖动，也可键盘操作）、上一首、播放暂停、连续播放、关闭
- 专辑详情每行都有播放键，标题下方另有「试听整张」
- 曲目总表每行左侧的编号即播放键（悬停显示图标，触屏常显）；正在播放的那一行会高亮
- `空格` 播放/暂停（输入框内和按钮上不劫持）
- 接了 **Media Session API**：系统媒体键与锁屏/控制中心能显示曲名、专辑、封面并控制播放
- **离线时页面完全不变**，播放控件保持禁用；加载失败会在播放列内就地说明，不会假装在播

### 想放整首歌

我没有、也不该去拿唱片录音。若你自己拥有音频，放进项目并在 `_data/local-audio.json` 登记：

```json
{
  "jay2000-1": "assets/audio/jay2000/01.m4a",
  "busy2007-3": "assets/audio/busy2007/03.m4a"
}
```

键是 `专辑id-曲目序号`（专辑 id 见 `_data/build.mjs`，如 `jay2000`、`busy2007`）。重新构建后本机文件优先，
官方试听留作后备；本机文件读不到时会自动退回试听并在播放列里说明。

```powershell
node _data/build.mjs
```

## 设计约定

| 项目 | 取值 |
|---|---|
| 设计读解 | 面向中文乐迷与设计敏感访客的唱片陈列，电影感编辑／美术馆图录语汇 |
| 三个旋钮 | `DESIGN_VARIANCE 8` · `MOTION_INTENSITY 7` · `VISUAL_DENSITY 3` |
| 主题 | 全站单一暗色主题，没有任何区块反向翻转 |
| 主色 | 仅一个强调色，朱砂 `#E0412B`，各区块完全一致 |
| 圆角 | 两套并写入注释：控件一律胶囊形，面板与图片一律 6px |
| 字体 | 思源宋体（标题）／Bodoni Moda（数字与拉丁）／思源黑体（正文） |
| 对比度 | 正文 ≥ 4.5:1；控件描边取到 3:1 下限（`--line-2`） |

专辑各自的 `--tint` 只用于详情页封面的环境光，由该封面平均色向底色混合 78% 得到，
不参与文字、描边、按钮或任何状态表达，因此不构成第二个强调色。

## 无障碍

- 键盘：全部控件可 Tab 到达，`:focus-visible` 有可见焦点环；强调色按钮上改用纸白色焦点环
- 数据显示行（图表条、发行间隔、合作者曲目）用 `role="button"` + `tabindex="0"`，并统一接 `Enter` / `Space`
- 详情抽屉：`role="dialog"` + `aria-modal`，焦点移入并在内部循环，`Esc` 关闭后焦点归位
- 跳转链接：`Tab` 第一站可跳到主内容
- 锚点偏移：`html { scroll-padding-top }` 让跳转目标与键盘焦点都不被固定顶栏遮挡（WCAG 2.2.4）
- 图片：53 张封面全部有 `alt`
- 图标：全部来自 Phosphor，纯装饰的加 `aria-hidden`
- 年轮：SVG 标为 `aria-hidden`，旁边另有一份等价的十六行可点击清单，键盘与读屏都能用
- 动效：`prefers-reduced-motion: reduce` 下横向卷动降级为原生横向滚动，歌名带停止位移，年轮直接就位
- 触控：主要控件高度 ≥ 44px

## 数据与版权

- 专辑名称、发行日期、曲目名称与时长取自 **Apple Music / iTunes 公开目录**。
- 繁体曲目名里混入的日文异体字（`説 晩 涙 啓`）已归一为 `說 晚 淚 啟`。
- 简介、年代分期文字为本站撰写，非官方文案。
- 合作者名单由曲目标题里的 `(feat. …)` / `(with …)` 标注解析而来，不是外部资料。
- 封面图像与录音版权归 **JVR Music International Ltd.** 所有。本站为个人收藏陈列，不作商业用途。
- 字体为开源字体（Noto Serif SC / Noto Sans SC / Bodoni Moda，SIL OFL），已本地托管。

## 重新构建数据

修改 `_data/build.mjs` 里的编辑层（英文名、简介、代表曲）或派生视图（年代分期定义）后：

```powershell
node _data/build.mjs          # 重新生成 js/data.js
```

数据来自 `_data/albums-raw.json`，如要重新抓取，可复用 `build.mjs` 上游的 iTunes 查询逻辑。
年代分期、合作者、长短篇、累积曲线、发行间隔全部由专辑资料在构建时算出，不会与专辑数据脱节。
