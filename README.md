# 声之年轮

周杰倫十六張錄音室專輯的靜態陳列站。2000 至 2026，一百七十五首作品。

零依賴、零建置、可離線。雙擊 `index.html` 即可打開，不需要安裝任何東西。

本倉託管於 GitHub（`discography-showcase`），push 後 CI 會自動跑一輪唯讀校驗。

---

## 能力

- **十四個展示面**：年輪、展櫃、年代分期、封面牆、數據面、長短篇、合作者、代表曲等，每面用不同佈局語言
- **年輪**：十六圈同心環依年份由內而外排列，圈寬對應曲目數，顏色取自該張封面平均色
- **試聽**：一百七十五首全部可播 30 秒官方片段，底部播放列支援進度拖動、上下首、連續播放
- **繁簡一鍵切換**：全站文案與搜尋索引同時切換，選擇記憶在 localStorage
- **檢索**：一百七十五首曲目總表，繁簡互通搜尋
- **全屏專輯抽屜**：封面、發行資訊、編輯文字、完整曲目，支援前後翻專輯
- **無障礙**：全鍵盤可達、焦點環可見、抽屜焦點鎖定、減少動效降級、觸控目標 ≥ 44px
- **離線可用**：封面、字體、腳本全部本地託管，斷網仍完整呈現

## 快速開始

```
雙擊 index.html
```

本地伺服器（可選，供手機同網段訪問或自動化驗證）：

```powershell
node _data/serve.mjs 8099
# 開啟 http://127.0.0.1:8099
```

## 邊界與資料

- 站內**不含任何完整錄音**，不含來源不明的音訊
- 試聽音源為 **Apple 隨目錄提供的官方 30 秒片段**，與中繼資料同一次請求返回
- 專輯名、發行日、曲目、時長取自 **Apple Music / iTunes 公開目錄**
- 簡介與年代分期文字為本站撰寫，非官方文案
- 封面圖像與錄音版權歸 **JVR Music International Ltd.** 所有；本站為個人非商業收藏陳列
- 字體為開源字體（Noto Serif SC / Noto Sans SC / Bodoni Moda，SIL OFL），已本地託管
- 頁面不含追蹤腳本、不含 Cookie、不發送任何資料到第三方；只有播放時才會連到 Apple 的 CDN

## 想聽整首

會員權益無法接入：網易雲等平台沒有面向第三方的官方播放介面，
非官方介面需服務端持有個人憑證，既有違服務條款又會暴露帳號。評估過程見
[.agents/notes/網易雲接入可行性.md](.agents/notes/網易雲接入可行性.md)。

若你自己擁有音檔，放進專案並在 `_data/local-audio.json` 登記：

```json
{
  "jay2000-1": "assets/audio/jay2000/01.m4a",
  "busy2007-3": "assets/audio/busy2007/03.m4a"
}
```

鍵為 `專輯id-曲目序號`（如 `jay2000`、`busy2007`）。`npm run build` 之後本機檔案優先，
官方試聽留作後備。
