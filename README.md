# 声之年轮

以年輪與數據陳列歌手的完整錄音室目錄：八位歌手、90 張專輯、1,104 首曲目，
每位歌手有自己的強調色與母題，同一歌手的每張專輯抽屜又各有從封面派生的色彩。
零執行期依賴、零建置、可離線：打開就選歌手，點進去是他的唱片年輪。

[![ci](https://github.com/cslkkl/discography-showcase/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/cslkkl/discography-showcase/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-2b6cb0)](LICENSE)
![node](https://img.shields.io/badge/node-24.15.0-43853d)

> **本倉庫不含任何音檔，也不含任何歌詞全文。** 要聽整首請自備合法取得的音源與歌詞，
> 所以 `git clone` 之後直接就能聽整首是不成立的；沒有音源的曲目一律回退官方 30 秒試聽。
> 邊界與資料來源見「[邊界與資料](#邊界與資料)」，放自己的音檔見「[想聽整首](#想聽整首自備音源)」。

## 能力

- **選歌手**：入口頁是一台立體唱片架，點兩側封面、點空白處或拖曳切換，點中央那張進入該歌手；
  新增歌手不需要改任何程式
- **認出歌手的人格**：強調色與專屬母題（水墨 / 網點 / 稜鏡 / 漣漪 / 溝槽 / 星夜 / 弧線 / 霓虹），
  主視覺就是歌手本名
- **換一種陳列語言**：十四個展示面（年輪、展櫃、年代分期、封面牆、數據面、長短篇、合作者、
  代表曲等），每面用不同佈局
- **讀年輪**：十六圈同心環依年份由內而外，圈寬對應曲目數，顏色取自該張封面平均色
- **聽**：一千一百零四首全部可播官方 30 秒片段；底部播放列支援進度拖動、上下首、
  順序與隨機播放（隨機範圍是當前歌手的全部專輯，不跨歌手）。
  放進自有音檔的曲目整首播放，播放列如實標示「本機音檔」或「官方 30 秒試聽」
- **看全屏歌詞**：自有音檔配同目錄 `.lrc` 即可開歌詞舞台，逐行呈現、逐字掃光，
  支援 `Esc` 退出與減少動效降級。
  **完整舞台的視覺層需要 `stage/`，而整個 `stage/` 目前不入庫**（`git ls-tree HEAD -- stage/`
  回 0 個檔案：它含上游 Folia 的逐字複本與 Vite 建置產物，體積大且可重建）。
  所以**全新 clone 得到的是基本舞台**：歌詞照常顯示、逐行呈現，但沒有完整視效，
  這是既有設計不是缺損。要完整舞台得另外取得 `stage/` 源目錄（上游基準 Folia 0.7.18），
  依目錄自帶的建置說明產出後把產物放到 `stage/dist/`，再重跑 `npm run stamp`
- **翻專輯抽屜**：封面、發行資訊、編輯文字、完整曲目，支援前後翻專輯
- **讀歌曲檔案**：點歌名開一份以「一首歌」為單位的檔案，含專輯／年份／時長、唱片視覺、
  創作資訊與**署名**（作詞／作曲／編曲／製作人；少數曲目另有混音、母帶、吉他等其他署名，
  實測 1322 筆裡 162 筆）。署名取自歌詞檔開頭的製作人員行（實測 1104 首裡 816 首有），
  沒有就留空
- **切繁簡**：入口與歌手頁同步，全站文案與檢索索引同時切換，選擇記憶在 localStorage
- **檢索**：1,104 首曲目總表，繁簡互通搜尋
- **鍵盤可用**：全鍵盤可達、焦點環可見、抽屜焦點鎖定、觸控目標 ≥ 44px、減少動效降級
- **離線可用**：封面、字體、腳本全部本地託管，斷網仍完整呈現

## 快速上手

```powershell
git clone https://github.com/cslkkl/discography-showcase.git
cd discography-showcase
npm run serve          # 開啟 http://127.0.0.1:8099
```

選一位歌手即可瀏覽；也可以直接雙擊 `index.html`（`file://` 下播放正常，
但歌詞讀不出來，因為 `XMLHttpRequest` 讀 sidecar 被 CORS 擋掉）。

## 想聽整首（自備音源）

站內每首的**官方音源**只放 Apple 官方 30 秒試聽，這是刻意保留的邊界：倉庫不含任何完整錄音。
會員權益無法接入第三方站，非官方介面需服務端持有個人憑證，既違服務條款又會暴露帳號；
評估過程見 [.agents/notes/網易雲接入可行性.md](.agents/notes/網易雲接入可行性.md)。

**若你自己擁有音檔**（自有 CD 抓軌、購買的 DRM-free 數位專輯），把它們放進
`assets/audio/<專輯id>/`，跑一次工具即可整首、離線播放。

> **本倉庫不含任何音檔，也不含任何歌詞全文。**
> 要聽整首，請**自備合法取得的音源與歌詞**（自有 CD 抓軌、購買的 DRM-free 數位專輯、
> 自購的電子歌詞）。本專案不分發、不代抓、不提供下載來源。

### 目錄與命名規則

```
assets/audio/
└── <專輯id>/                    ← 只掃這一層，不會遞歸到更深的子目錄
    ├── 01 以父之名.flac          ← 音檔（7 種擴展名，見下）
    └── 01 以父之名.lrc           ← 歌詞 sidecar：與音檔同目錄、同主檔名
```

- **專輯 id**：用 `node _data/local-audio.mjs --list-albums` 查（左欄就是 id，例如 `yeh2003`），
  或到 `_data/artists/<歌手id>/` 的資料夾與 `js/data.js` 裡對
- **音檔**：`assets/audio/<專輯id>/` 下任意檔名，支援
  `.flac` `.mp3` `.m4a` `.aac` `.opus` `.ogg` `.wav`（大小寫不敏感）。
  對應曲目有兩條路徑：① 檔名以**序號開頭**（`01`、`1 -`、`03.`、`[05]`）就取該序號；
  ② 否則把檔名正規化（去空白標點、全形轉半形）後與該專輯曲名比對（繁體原名與簡體轉換都試）
- **歌詞**：`.lrc` 放**同一個目錄**，與音檔**同主檔名**最穩；找不到同名時退回「同序號」的 `.lrc`。
  沒有 `.lrc` 就只有音檔、沒有歌詞
- **範例**（周杰倫《葉惠美》第 1 首〈以父之名〉，專輯 id `yeh2003`）：

```
assets/audio/yeh2003/01 以父之名.flac
assets/audio/yeh2003/01 以父之名.lrc
```

### 三步走

```powershell
# 1) 查專輯 id（左欄）與該專輯的曲目序號
node _data/local-audio.mjs --list-albums

# 2) 把音檔（與同名 .lrc）放進 assets/audio/<專輯id>/，然後掃描登記 + 本機態建置
npm run listen          # = node _data/local-audio.mjs --write && node _data/build.mjs --local

# 3) 起站點確認
npm run serve           # http://127.0.0.1:8099，進歌手頁按播放
```

`npm run listen` 會逐張專輯印出「對上幾首 / 共幾首」，並列出**缺哪幾首**、**哪些檔對不上**、
**哪兩個檔撞同一個序號**、以及 FLAC 檔頭時長與目錄資料相差超過 3 秒的曲目
（用來抓「序號寫錯導致抓錯歌」）。檔名很亂時可先跑
`node _data/local-audio.mjs --write --rename`，它只把序號補正成兩位數、保留後面的描述文字。

### 對不上會怎樣（不會壞，只會降級）

- 某首沒有本機音檔：該首**自動回退到 Apple 官方 30 秒試聽**，按鈕由「整首播放」變成
  「試聽 30 秒」，播放列標「官方 30 秒試聽」
- 某首有音檔但沒有 `.lrc`：能整首播放，但**沒有歌詞舞台**（入口就地說明「這首沒有本機歌詞」）
- 本機檔案損壞或編碼不支援：頁面提示「本機檔案無法載入，已改用官方試聽」，播放不中斷
- 目錄名不是已知專輯 id：整個目錄跳過並在報告裡列出，不會靜默忽略

### 這些檔案永遠不進版本庫

`assets/audio/`、`_data/local-audio.json`、`_data/local-lyrics.json` 都在
[.gitignore](.gitignore) 裡（第 31 至 33 行），所以音檔與歌詞全文只留在你本機。
換一台機器或部署到遠端時，播放會自動回退到官方試聽。

## 邊界與資料

- **倉庫不含任何完整錄音**，也不含來源不明的音訊
- 官方音源為 **Apple 隨目錄提供的 30 秒片段**，與中繼資料同一次請求返回
- 自有音檔只留在使用者本機，不進版本庫；播放時本機檔案優先，官方片段留作後備
- 專輯名、發行日、曲目、時長取自 **Apple Music / iTunes 公開目錄**（TW 店）
- Taylor's Version 重錄版非新專輯，不收錄；各歌手的精選與現場專輯不收錄
  （介紹中如實說明的混合型專輯除外）
- 簡介與年代分期文字為本站撰寫，非官方文案
- 封面圖像與錄音版權歸各自權利人所有；本站為個人非商業收藏陳列
- 字體為開源字體（Noto Serif SC / Noto Sans SC / Bodoni Moda，SIL OFL），已本地託管
- 頁面不含追蹤腳本、不含 Cookie、不發送任何資料到第三方；只有播放時才連到 Apple 的 CDN

## 想加一位歌手

收錄新歌手只要新增一個資料夾 `_data/artists/<歌手id>/`（事實檔 + 一份手寫 `meta.mjs`），
再跑 `npm run build`，不必改 `build.mjs`。資料夾形狀與抓取、配色、封面、署名四支腳本的
完整步驟見 [_data/artists/README.md](_data/artists/README.md)；
建置後入口頁會多出一行，歌手頁的主題（強調色、印章、題名、母題）全由 `meta.mjs` 的
`theme` 驅動。
