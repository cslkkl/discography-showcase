# notes/ — 决策与依据记录

非活文档。记录「当时为什么这么定」，不随代码演进追改。

## 两类记录

| 类型 | 触发源 | 命名 | 特征 |
|---|---|---|---|
| 决策 | 做选择 | `YYYY-MM-DD-<主题>` | 在几个方案里挑了一个，必含替代方案 |
| 依据 | 做调查 | 可省日期 | 看事实、对照、得结论，本身不含选择 |

分界判据：触发源是「做选择」还是「做调查」。
调查结论若喂给某个决策，在依据类里用 `## 支撑的决策` 指回，不复制决策内容。

## 与事故复盘的分界

- 事故触发 → `docs/postmortem/`（按需创建，现无内容）
- 决策触发或调查触发 → 本目录

## 怎么用

- 想知道某个设计为什么是这样 → 按日期或主题找对应篇
- 想推翻某个决定 → 先读该篇的「替代方案」，确认没有重走已否决的路
- 记录已失效 → 改第 3 行状态并附理由，不删除

格式与状态规则见 [AGENTS.md](AGENTS.md)。
