# 決策：視覺與交互高級化（2026-10-14）

状态：生效

## 問題

維護者要求把站點從「功能完整」推到「視覺與交互高級化」：要有縱深、有打光、
有銘牌字體、有時間的形狀。硬約束不變：零執行期依賴、雙擊 `index.html` 即可用、離線可用、唯一強調色。
四個要先拍板的技術分岔擺在面前：

1. 重疊封面堆的縱深用祖先 `perspective` ＋ 子層 `preserve-3d`，還是每張元素自己的 `perspective()`？
2. 展台的「環境光」取歌手的強調色，還是取唱片的封面色？
3. 入口與首屏的兩個主要入口維持膠囊色塊按鈕，還是改成文字型按鈕？
4. 拉丁銘牌缺一款高對比度的老式襯線，是引進新字體，還是沿用既有的 Bodoni Moda？

## 決策

- **縱深：每元素 `perspective()`，父層不掛透視、不掛 `preserve-3d`**。
  歌手頁 `.fan-card` 與入口頁 `.ld-group` 都把 `perspective(1400px)` 寫進自己的
  `transform` 函式清單（在 `translateZ` 之前），並保留 `translateZ` 的縱深。
  不重疊的展櫃（`.album-card`）與封面牆（`.wall-tile`）仍保留祖先 `perspective: 1500px`
  ＋ 子層 `preserve-3d`：實測那兩處點擊正常、開抽屜成功
- **環境光取封面色**：`--amb` 取該歌手第一張封面所屬專輯的構建期平均色 `sourceAvg`，
  以 `"r, g, b"` 寫進容器；CSS 只以 `rgba(var(--amb), α)` 畫柔光。歌手強調色 `--accent`
  仍只管印章、選中態、焦點與裝飾。兩者是互斥的兩條通道
- **按鈕改文字型**：入口 `.ld-cta` 與歌手頁 `.hero-cta` 內的按鈕改成透明底、無圓角的
  文字型按鈕，hover 時底部長出 1px 強調色細線；`.ld-cta` 的箭頭用文字符號 `→`，不用 svg。
  其餘圖示型控制項（頂欄、展櫃箭頭、播放列、抽屜）一律維持 `--r-pill`
- **只引進一款新字體**：Cormorant Garamond（latin + latin-ext，400／500，2 檔共 71,376 B），
  自託管進 `assets/fonts/`，授權 OFL 見 `assets/fonts/licenses/OFL-CormorantGaramond.txt`，
  抓取腳本 `_data/fetch-display-font.ps1`（純 ASCII、冪等：重跑輸出 `downloaded=0 reused=4`
  且字體表 SHA256 不變）。字體鎖由三族變四族
- **字體表納入版本戳**：`_data/stamp-assets.mjs` 的刷版本範圍加入 `assets/fonts/fonts.css`，
  因此 `npm run stamp` 的版本字串同時涵蓋 `js/`、`css/` 與字體表

## 替代方案（強制）

- **祖先 `perspective` ＋ 子層 `preserve-3d`**：否決，因為它製造了一個真實的可點擊性回歸。
  兩者合起來形成真正的 3D 脈絡，被 `translateZ` 推到後面的卡片在真實指標下命中不到自己。
  歌手頁主視覺實測：在 `.fan` 子樹內做 64×44 網格取樣、只看落在卡片幾何範圍內的 1586 點，
  其中 439 點（27.7%）穿透到宿主 `div.fan`，命中率只有 72.3%；真實滑鼠點擊的
  `click.target` 就是 `DIV.fan`。入口頁同因：點右二封面只前進一位（落進「點空白處進退一位」
  的兜底），`click.target` 是 `UL.ld-groups`。關鍵是 `document.elementsFromPoint` 仍會回報
  該張卡，所以 **DOM 斷言會把這條回歸判成「可用」**。改成每張卡自己的 `perspective(1400px)`
  之後，命中率回到 100%（獨立複現 68/68 點、12×8 網格、jay-chou、CSS 1440），
  而遠端封面的投影寬只由 241px 變 235px，縱深幾乎無損；入口頁修好後點右二＝選中該歌手
  （陶喆 +2 命中周杰倫，`target` 為 `IMG`）
- **環境光取歌手強調色**：否決。原本 `.ld-glow` 只有單一強調色的兩圈暈，切歌手時背景
  不跟著唱片換色，一張紅封面與一張藍封面看起來是同一個展台；強調色該管的是身分
  （印章、選中態），不是打光。改用封面色後，八位歌手的 `--amb` 各自等於該歌手
  `covers[0]` 所屬專輯的 `sourceAvg`：16, 64, 138／121, 76, 105／114, 97, 91／161, 126, 150／
  171, 165, 159／203, 191, 175／87, 21, 30／142, 162, 188
- **兩顆入口維持膠囊色塊**：否決。展廳入口不是膠囊按鈕，色塊也讓「進入檔案」與
  頂欄那些真正的圖示型控制項混成同一種元件語言。改文字型後，焦點圈也跟著回到強調色
- **不引進新字體，沿用 Bodoni Moda**：否決。Bodoni 是 Didone，筆畫對比極高，
  在 `.75rem` 這種小字號配 `.22em` 字距時會散成一份清單而不是銘牌；Cormorant Garamond
  是老式襯線，同樣字距下仍讀得出「館名銅牌」的刻意感。這也是 `.ha-en` 的字距由 `.34em`
  收到 `.2em` 的原因
- **連中文標題也換字體**：否決。中文標題的 Noto Serif SC 已是自託管子集；
  再換一套 CJK 襯線要重做全部子集的授權與體積預算，收益只在標題筆形。
  新字體只用於拉丁銘牌，漢字落到字組裡的 Noto Serif SC
- **每次改字體檔就手動改 HTML 的版本戳**：否決。字體表換檔而 HTML 引用沒換時，舊快取會
  缺新的 face 並**靜默回退**到字組裡的下一款字體，畫面只是「好像不太一樣」，沒有人會發現。
  納入 `npm run stamp` 的自動範圍才有守衛
- **把 `document.elementsFromPoint` 當命中真相**：否決。它會回報被遮住的卡片；實測對右鄰
  那張，DOM 命中測試回報是它，真實點擊卻落在中央那張、還誤開了抽屜。挑點要用瀏覽器
  自己的 `el.matches(':hover')`，驗證要用 `page.mouse.click()`；測試輔助函式不得在真實
  點擊失敗時靜默回退成 `element.click()`

## 複現方式

- 命中取樣：對歌手頁主視覺（`artist.html?a=<id>`）在 `.fan` 子樹內做 64×44 均勻網格取樣，
  只取落在卡片幾何範圍內的點，逐點 `page.mouse.click` 並比對 `click.target`；
  另以 `el.matches(':hover')` 挑點作為輔助。**不要**用 `document.elementsFromPoint` 當真相
- 入口頁：點右二封面後讀選中索引與 `click.target`（修好後應為 `IMG`，不是 `UL.ld-groups`）
- 環境光：讀 `.ld-hero` 的 `--amb`，與 `js/data.js` 內該歌手 `covers[0]` 所屬專輯的
  `sourceAvg` 逐位比對
- 折線：載入後讀 `getBoundingClientRect().bottom` 與頁面內的 `innerWidth`
- 測量環境：`viewport` 參數本身就是 CSS 像素，直接請求目標尺寸即可，
  但**必須在頁面內讀 `innerWidth` 自證**。共用 MCP 瀏覽器視窗可能帶非 1 的縮放
  （本專案遇過視窗被縮到 75%，`setViewportSize(1440, 900)` 實際得到 CSS 1920×1200）；
  用獨立進程 `chromium.launch()` ＋ `newContext({ viewport: ... })` 時請求值即所得
  （實測 1440×900 → `innerWidth 1440`、`dpr = 1`，1366×768 與 390×844 同）。不要把
  「乘 0.75」寫進測試輔助函式

## 其他同批落地的修正

- **群組透明度會壓平 3D 子樹**：`.fan.is-shifting` 原本用群組 `opacity: .26`，
  外側封面在換片頭尾各跳一次（寬度 241 → 257.7 → 241，7.2%）。
  改成把暗度下放到每一張卡（`opacity: calc(var(--fo, 1) * .26)`），群組只留
  `transform: scale(.972)`
- **入場錯峰不得騎在換位上**：`.fan-card` 的 `transition-delay: calc(--i * 95ms + 240ms)`
  配上 1.15s 入場時長，讓一次換片要 1458–2263ms 才停穩。加
  `.fan.is-shifting .fan-card, .fan.is-arriving .fan-card { transition-delay: 0ms; transition-duration: .62s; }`
  後停穩 ~1042ms
- **CJK 的 `ch` 單位陷阱再次出現**：`ch` 以 CJK 字體解析只有半個漢字寬，`30ch` 會把中文
  句子切成兩三行（實測 391px 下 229.9px／3 行）。`.ha-note` 與 `.ld-note` 都改用
  `max-width: min(100%, 30rem)`
- **減少動效要連 `animation-delay` 一起歸零**：只把 duration 壓成 0 而留著 delay，
  分階段入場的元素會停在起始態（`opacity: 0`）近三秒才出現。末節已加
  `animation-delay: 0ms !important` 與 `transition-delay: 0ms !important`
