# notes/ — 规则层

继承根规则，见 [../../AGENTS.md](../../AGENTS.md)。

本目录特有约束：

- 每篇第 3 行必须是状态行，四值之一：`状态：生效` / `状态：被取代` / `状态：已否决` / `状态：已归档`
- `被取代` 必须跟指针行指向新记录；`已归档` / `已否决` 必须跟一句话理由
- 决策类必须含 `## 替代方案（强制）`，写清试过什么、为什么不行
- 失效记录就地标记状态，不建 `archived/` 子目录
- 不建索引文件，不逐篇列清单
- 活文档用现在时描述已落地的事实；事实性变化就地更新，决策反转才另写新篇

写作约定见 [README.md](README.md)。
