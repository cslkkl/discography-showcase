# 依据：开源免费音源调查

状态：生效

## 背景

維護者問能否從 GitHub 找現成的開源免費音源，或自未授權聚合站批量抓取後接入本站實現整首播放。
本記錄是對「有沒有合法免費的整首音源」的一次實地調查。

## 结论

**不存在。** 這五位歌手的 1039 首錄音全在版權保護期內，開放目錄裡沒有任何原始錄音；
能找到的都是同一類：未授權上傳或非官方解析，加個許可標籤不等於取得授權。

三類實測：

1. GitHub 上的音樂專案，全是非官方解析／下載器
   代表：`CharlesPikachu/musicdl`（自稱無損下載器，覆蓋網易雲、QQ、酷狗、酷我、咪咕、
   TIDAL、YouTube、Apple Music、Spotify、Qobuz、SoundCloud）、`guohuiyuan/go-music-dl`、
   `mkr-0920/music-api-server`（網易雲與 QQ 解析 API）、`LX Music` 系列。
   它們不託管音源，而是繞過平台授權取流，即已否決的「非官方介面」路線。
   這類專案另有工程風險：平台改加密即失效、部分綁定私有服務端、發行物常不透明。

2. archive.org 有這些歌手的商業專輯，且掛著 CC 許可——但許可是上傳者貼的，無權授予
   實測 `creator:"張學友"` 命中 3 筆，全部帶 `CC BY-NC-ND 4.0`：
   `雪狼湖 [粵語版] [Disc 2]`、`等你等到我心痛 (1993)`、`釋放自己 (1998)`。
   Taylor Swift 命中 50 筆，其中 `1989 (Deluxe)` 標 `CC BY-NC-ND`、
   `Taylor Swift — Picture To Burn 2006` 標 `CC0`。
   這些錄音的權利人是環球、JVR、Republic 等，不是上傳者；
   上傳者自行附加的 CC 標籤**不構成授權**，取用與抓盜版站同質，
   而且更容易讓人誤以為自己合法。此類條目也會隨投訴下架，做資料依賴必然鏈斷。

3. 真正開放許可的內容裡沒有這五位歌手的原始錄音
   同樣條件下能搜到的只是粉絲鋼琴翻彈、同人畫作、新聞片段與評論節目，
   即 `creator:"Jay Chou"` 命中的 4 筆音頻全部無許可、且是翻彈或訪談。
   公有領域與 CC 曲庫（Jamendo、Free Music Archive、ccMixter、Musopen、
   archive.org 的 etree 現場錄音庫）不含這批商業錄音。

## 影响

- 整首播放的合法路徑只有兩條：自有合法音檔（`assets/audio/` + `local-audio.mjs`）、
  或離開本站去官方平台；後者只需深鏈，是尚可補的一步
- 倉庫可見性不改變本結論：私密只免去分發環節，未授權複製依然存在
- 若日後要為**其他**歌手找免費音源，上述 CC 曲庫才是起點；
  前提是該歌手本身以開放許可發行
