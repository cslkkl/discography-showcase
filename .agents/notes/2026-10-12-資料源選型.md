# 决策：資料源改用 iTunes + MusicBrainz（2026-10-12）

状态：生效

## 问题

需要十六張專輯的權威事實：發行日、曲目、時長、封面、試聽網址。
原始計畫以維基百科為主源。

## 决策

- 事實層取自 iTunes Lookup API（`entity=song`）與 MusicBrainz
- 文案層寫在 `_data/build.mjs` 的 `META` 內，由人工撰寫
- 全部事實落盤到 `_data/albums-raw.json`，`build.mjs` 只做轉換不算事實

## 替代方案（强制）

- 維基百科：本環境網路不可達，且條目內的曲目表本身就可能滯後
- 純人工錄入：175 首的時長與發行日人工抄錄必錯，且無法重跑復現
- 只用 iTunes：缺部分專輯的發行資訊校驗來源，且第 16 張需交叉確認

## 影响

- 事實可重跑復現：`npm run build` 即可由 `albums-raw.json` 重生成 `js/data.js`
- 代價是 `albums-raw.json` 成為必須入庫的中間產物，且依賴外部 API 抓取腳本
- iTunes 回傳日文新字體，需 `KANJI_FIX` 轉正（見根 AGENTS 活躍坑）
- 第 16 張《太陽之子》以網路搜尋交叉確認發行日為 2026-03-25
