# 决策：拒絕 ui-ux-pro-max 推薦的 indigo 配色與 Brutalism 風格（2026-10-12）

状态：生效

## 问题

`ui-ux-pro-max` 的 `--design-system` 對本專案給出建議，需判斷是否採用。

## 决策

- 配色不採用其建議的 indigo / purple（`#1E1B4B` / `#4338CA`）與 Inter 字體
- 風格不採用其建議的 Brutalism
- 維持深墨底 + 朱砂 `#E0412B`、Noto Serif SC / Noto Sans SC / Bodoni Moda
- 只採納其 UX 規則：對比度下限、44px 觸控目標、焦點不被遮擋（轉為 `scroll-padding-top`）

## 替代方案（强制）

- 全盤採用其建議：indigo 紫與本站「周杰倫 / 華語流行 / 朱砂印章」的題材無關，
  且會讓頁面變成典型的 AI 生成配色，與「前端必須高端」的要求相衝突
- 完全不用該 skill：會漏掉它真正有價值的部分——那些可量化的 UX 規則

## 影响

- 設計方向由題材決定，不由工具預設決定
- 該 skill 作為 UX 規則庫使用，不作為配色與風格來源
- 後續若再引入外部 skill，同樣只吸收與題材相容的部分
